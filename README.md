# Student Registration System

## Project Title

Student Registration System

## Problem Statement

Managing student registration records manually can be time-consuming and prone to errors. Educational institutions require a system that allows efficient storage, retrieval, updating, and management of student information. This project provides an object-oriented solution for handling student registration data in a structured and user-friendly manner.

## Project Description

The Student Registration System is an Object-Oriented Programming (OOP) project developed to manage student records efficiently. The system allows users to add, view, update, search, and delete student information while demonstrating key OOP concepts such as encapsulation, inheritance, polymorphism, and abstraction.

## Features

* Add new student records
* View registered students
* Update student details
* Delete student records
* Search for students
* Simple and user-friendly interface
* Organized object-oriented design

## How to Run the Project

### Prerequisites

* Java JDK 8 or later
* IDE (IntelliJ IDEA, Eclipse, or NetBeans)

### Steps

1. Clone the repository:
   git clone https://github.com/anjosi1/student-registration-system.git

2. Open the project in your preferred Java IDE.

3. Build the project.

4. Run the main class.

5. Use the application to manage student registration records.
